雄霸AI v0.2.0｜使用说明
====================

安装与更新
1. 用户端运行 ImageWorkbench-0.2.0-x64.exe；管理机运行 ImageWorkbenchAdmin-0.2.0-x64.exe。
2. 已安装画境工作台的用户会看到可选更新弹窗，弹窗列出本次更新内容。可选择稍后更新。
3. 这是原软件的升级。原审批绑定、设备身份、API Key、历史记录和管理员密码沿用，不需要重新申请。

开始使用
1. 首次使用的同事在申请页输入用户名和密码；管理员在管理端批准并设置期限。已批准设备更新后直接进入。
2. 接口页填写基础 URL 和 API Key，点击“连接并进入”。工作台内的“接口设置”可以随时更换地址和 Key。
3. 点击“同步模型”读取当前端口可识别的文本、绘图和视频模型。不同端口的 Key 分别加密保存。若接口没有标准模型列表或协议无法识别，软件会提示需要适配；请提供该端口的接口文档。
4. 在输入框下方选择模式和模型。绘图、视频模式还可选择画幅、分辨率；视频模型按能力显示时长。模型不支持的参数不会提供。
5. 输入 @ 可引用已添加的文件并调整参考权重。支持的文件类型以当前模型的能力为准。可点击上传，也可从桌面或文件夹拖入。Enter 发送，Shift+Enter 换行。
6. 文本回答会先显示思考状态；接口提供思考内容时会展示，完成后默认折叠。视频和图片生成可同时提交多个任务，生成历史会显示各任务进度。

界面与文件
1. 左侧 Logo、新建对话、工作区按钮和底部接口设置固定；只有左侧“历史对话”列表滚动。右侧对话与生成历史各自滚动，提示词输入框固定在下方。
2. 双击生成图片或参考图片可放大。生成图片右键选“复制原图”可复制到剪贴板，也可点击保存。生成文件会在两小时后自动删除，请及时另存。
3. 点击“生成历史”查看媒体任务；“清空全部历史”会删除本机历史和未另存的临时媒体。
4. “壁纸透明度”滑杆可调节背景清晰度。管理端可上传或切换动态、静态主题，用户端联网后会自动同步。

管理端
1. 用原管理员密码解锁。待审批页可批准、驳回并设置期限；绑定管理可重命名、解绑、换绑、调整期限或删除记录。
2. 原管理员密码库与申请记录沿用。管理端仅留在管理机，不要发给普通用户。

常见问题
- 接口调用失败：检查该端口的 Key、额度、模型权限及网络连接。同步出模型不代表账号拥有调用权限。
- 模型显示“需要适配”：该端口缺少可识别调用协议，请提供官方接口文档。
- 换机：在新电脑提交申请，由管理员在绑定管理中换绑。普通软件更新不需要换绑。
- 审批状态未刷新：确认网络正常，再点申请页“刷新审批状态”；工作台也会定期复核。
