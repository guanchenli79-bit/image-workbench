画境工作台 v0.1.15｜使用说明
============================

安装与更新
1. 同事安装 ImageWorkbench-0.1.15-x64.exe，管理机安装 ImageWorkbenchAdmin-0.1.15-x64.exe。
2. 已安装旧版的同事可以在软件更新弹窗中选择下载和安装，也可直接运行新版安装包。更新不会清除设备身份、API Key、历史任务或壁纸设置。
3. 更新弹窗显示本次修改内容，用户可选择“稍后再说”；不会强制更新。

用户申请与设备绑定
1. 首次打开客户端，在右侧浮窗填写姓名和 11 位手机号，点击“提交使用申请”。申请会带上当前机器码发送给管理端。
2. 等待管理员批准。工作台约每 30 秒自动查询一次，批准后自动进入创作页面，无需输入卡密。更新软件后会识别同一设备身份，无需重新申请。
3. 同一手机号只能有一台有效绑定机器。同一机器也只能有一条有效绑定。绑定到期或被解绑后，需要重新提交申请。
4. 设备身份保存在当前 Windows 用户的 AppData 目录，与安装目录分开。重装 Windows、重置机器标识、清理该用户的设备身份数据，可能需要管理员重新审批。
5. 使用申请需要联网；正常使用时会定期复核。审批服务连续不可达超过五分钟时会暂时限制访问，网络恢复后自动复核。管理员解绑或换绑后，旧机器在下一次成功复核时失效。
6. 旧版已激活的卡密用户在原有效期内仍可继续使用，无需因本次更新重新输入卡密。管理端“旧版记录”可查看本机留存的签发历史；新申请统一保存在在线审批库。

管理端审批与绑定
1. 仅在管理机打开“画境使用审批管理”。继续使用之前设置的管理员密码；首次使用则设置至少八位密码。
   本次升级后第一次输入管理员密码时，管理令牌会自动迁入密码加密管理库；无需额外填写。
2. “待审批”页面显示用户姓名、手机号、机器码和申请时间。选择截止日期并点击“批准申请”，或点击“驳回”。
3. “绑定管理”页面可查看已批准、到期、解绑和驳回的记录。可修改有效期、解绑、换绑或手动永久删除。
4. 换绑：让同一手机号在新电脑先提交申请；原绑定行会出现新机器选择框。选择目标后点击“换绑至新机器”，原机器解绑，新机器继承原有效期。
5. 在线 Cloudflare D1 是新版申请与绑定的统一数据源；记录不会因更换管理机或客户端更新而消失。旧版本机加密管理库和备份仍保留，请继续备份 admin-vault.json 和 admin-vault.json.bak。管理员密码无法找回。
6. 管理端请勿发给普通用户。不要公开 Cloudflare 管理凭据或管理机用户数据。

API 与生图
1. 进入工作台后点击右上角“设置 API Key”，填写自己所用中转站的 API Key 和基础地址。默认 Geeknow 地址为 https://www.geeknow.top；Grsai 为 https://grsaiapi.com。不同地址的 Key 分别加密保存。
2. 保存后会同步生图模型，或手动点击“同步模型”。未知端口无法识别参数时会提示需要适配，不会盲目提交生成任务。
3. 可选择模型、画幅和分辨率，填写提示词并添加参考图。参考图可点击选择，也可从桌面、文件夹拖入；双击缩略图可放大。
4. 提交一个任务后可继续提交其他任务。每项任务独立显示进度。双击生成图片可放大；右键选择“复制图像（原尺寸）”，或保存原图到电脑。
5. 生成的本机临时图片和视频会在两小时后自动删除，请及时保存。永久另存的文件不受影响。“清空历史”会删除本机历史任务和未另存的临时媒体。
6. 点击右上角按钮可切换浅色和深色模式；“壁纸”按钮可打开不透明度滑杆，0% 关闭背景，100% 完整显示。创作画布和输入面板使用半透明背景；设置保存在本机，更新后仍保留。
7. 模型、画幅和分辨率使用平滑下拉面板；可用鼠标选择，也可用方向键、Home／End、Enter 和 Esc 操作。

页面主题
用户端默认内置所提供的 Wallpaper Engine 动态视频，登录页和工作台都能显示。管理端“页面主题”可以添加、选择、删除 GIF／动态 WebP、静态图片和 MP4／WebM 视频。点击“设为当前”后，用户端联网时自动同步登录页和工作台背景，不用再发布安装包；用户自己的不透明度设置不受影响。Wallpaper Engine 视频项目可直接导入；动态场景可录制主显示器八秒，先本机预览再确认上传。上传到公开素材库的主题可被访问仓库的人查看，请不要录入私人内容。

常见问题
申请提交失败：检查网络与系统代理。机器码无法读取时请重启软件，或检查 Windows 机器标识。
申请迟迟未通过：请管理员在“待审批”页刷新；批准后客户端最多约 30 秒自动进入。
换机无法登录：新机器先用原手机号提交申请，由管理员在旧绑定行选择目标机器换绑。
模型生成失败：检查对应中转站的 Key、余额、模型权限和历史任务错误信息。同步模型成功不保证账户拥有该模型调用权限。
