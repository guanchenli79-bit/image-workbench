画境工作台｜使用说明
====================

安装
双击 ImageWorkbench-0.1.9-x64.exe 安装。安装后打开“画境工作台”。
本安装包适用于 Windows x64。将安装包发给朋友即可；他们需要填写自己的 API Key。

首次激活
1. 更新后打开工作台，会先看到动态壁纸和右侧激活框。点击“复制”把当前机器码发给管理员。
2. 管理员在管理端填写机器码和有效期，生成格式为 DP-XXXX-XXXX-XXXX 的卡密，并发给该用户。
3. 用户在激活框粘贴卡密，联网核验后即可进入工作台。之后可离线使用到授权到期；每台机器只对应一张当前有效卡密。
4. 重装 Windows 或重置机器标识可能改变机器码，需联系管理员解绑旧机器并重新签发。卡密与 Geeknow API Key 是两个不同的凭据。

管理机签发与解绑
1. 仅在管理机安装 ImageWorkbenchAdmin-0.1.9-x64.exe，打开“画境卡密管理”。管理机需安装并登录 GitHub CLI（gh），账号要有 guanchenli79-bit/image-workbench 仓库的写入权限。
2. 输入用户机器码，选截止日期，点“生成并同步卡密”。卡密只在签发时显示，请立即复制发给对应用户。重新签发同一机器会替换旧卡密。
3. 右侧“当前授权”可查看到期时间，点击“解绑机器”即可从授权库移除。已联网的用户在下次成功复核时失效；离线用户最晚可使用到本地授权到期。
4. GitHub 授权库只保存机器码和卡密的哈希与有效期，不保存明文。管理端请勿发给普通用户，也不要向他人提供管理机的 GitHub 登录凭据。

首次连接 API
1. 点击右上角“设置 API Key”。
2. 把 Geeknow 控制台生成的完整 API Key 粘贴进去。接口地址默认是 https://www.geeknow.top（官方 API 地址，不是 geeknow.ai/console 控制台地址）。
3. 点击“测试连接”，确认当前 Key 可以读取模型列表；再点击“保存设置”。
4. Key 使用 Windows 安全存储加密后保存在当前用户电脑上，不包含在安装包内。

创作与保存
1. 顶部切换“图像生成”或“视频生成”。右侧可填写提示词、选择模型、画幅和分辨率，按需添加参考图。
2. auto 会优先根据第一张参考图识别画幅；没有参考图时根据提示词识别，最后默认 1:1。
3. 图像分辨率选项随模型变化。例如 GPT Image 2 VIP 可选 1K、2K、4K；未确认有可切换档位的模型显示“模型默认”。高分辨率可能增加扣费，请在提交前核对。画幅会按所选模型的能力适配，“实际提交尺寸”会在分辨率下方显示。
   参考图可以点击选择，也可以直接从桌面或文件夹拖入软件窗口。支持 PNG、JPG、WEBP，单张不超过 10 MB，最多 10 张。双击参考图缩略图可放大查看；按 Esc 或点击右上角关闭。
4. 点击“立即生成”，结果和进度出现在左侧；“全部历史”可查看所有记录。
   提交后可以继续修改提示词、模型或参考图，再点击“继续生成”提交其他任务；多个任务可同时进行。每条任务都有独立的进度条。接口返回百分比时显示实际进度；未返回时显示“处理中”动画，完成后显示 100%。
   提示词输入框右上角有展开按钮，点击后会增大输入区域，再点一次收起。
5. 生成图片后，在图片上点右键可选“复制图像（原尺寸）”，然后粘贴到支持图片的聊天窗口、文档或编辑软件；复制不缩放、不裁剪。也可选“保存原图到电脑”，或点击作品卡片中的“保存作品”。
   双击已生成的图片可放大预览；按 Esc 或点击右上角关闭。
6. 生成视频需通过“保存作品”永久保存。
7. 在“全部历史”中点击“清空历史”，确认后会删除所有历史任务和未另存的本机临时生成文件；已永久保存到电脑其他位置的作品不受影响。

重要：生成内容会在两小时后自动删除，请及时保存。
本应用从生成完成时起计时，运行时自动清理本机临时图片与视频；关闭应用后，下次启动会立即清理已到期文件。历史中的提示词和状态保留，过期媒体不能恢复。通过“保存作品”永久保存的文件不受影响。远端服务的文件与素材保留期限由服务方管理。

自动更新
正式安装版会在启动时及运行期间定期检查 GitHub Releases。发现新版本后会弹出更新窗口，并展示从当前版本到新版本的更新说明；用户可选“下载更新”或“稍后再说”，稍后可点击顶部更新按钮继续。下载完成后，由用户点击“重启并安装”，不会强制更新，也不会因关闭应用而自动安装。联网才能收到更新。管理机发布时需要修改 package.json 版本、重新打包，并在 GitHub Release 填写更新说明，发布安装包、blockmap 和 latest.yml。

界面外观
点击右上角“深色模式”或“浅色模式”按钮切换。应用会记住这台电脑上的选择。

常见问题
测试连接失败：检查 Key 是否完整、接口地址、网络与账号状态。本应用会读取 Windows 系统代理；也支持 HTTP_PROXY / HTTPS_PROXY 环境变量。
某个模型生成失败：请看历史区错误信息，并检查当前 Key 的模型权限、余额和接口状态。模型列表是内置的，但模型访问权由 Geeknow 账号决定。
Midjourney 显示“Submit success”却被标成失败：更新到新版后重新打开工作台，历史任务会自动恢复并查询结果。已另存的图片不受两小时本机临时缓存清理影响。
Midjourney 使用多张参考图时：新版会先逐张上传图片，再把图片地址放进提示词提交。若上传失败，历史区会指出第几张图片；若出现 do_request_failed，表示上游处理请求失败，可先精简提示词、减少参考图再试。应用不会自动重新提交生成，避免重复计费。
GPT Image 2 VIP 提示“上游安全系统拒绝”：这是服务端的内容审核结果。请检查提示词和参考图后自行修改；若认为误判，可把历史区显示的请求 ID 提供给 Geeknow 客服查询。更换 API Key 或反复原样提交通常不能解决此类拒绝。
参考图上传失败：部分模型需要 Geeknow 素材上传服务提供公网地址，按错误提示检查服务。
GPT Image 2 VIP 等 GPT Image 模型使用参考图：新版会先上传参考图，再以图片 URL 提交异步生成。若上传失败，错误会标明第几张图片。生成进度会在历史记录中更新；不要连续重复提交同一任务，以免重复计费。
复制图像失败：图片可能已经过期，或该图片格式暂不受系统剪贴板支持；请在过期前使用“保存原图到电脑”。
