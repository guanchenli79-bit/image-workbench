# 画境工作台

Windows 图像与视频创作桌面应用。支持 Geeknow、Grsai 和可识别的 OpenAI 兼容接口；各接口地址分别保存 API Key。

## 功能

- 模型、画幅和分辨率选择，提示词和参考图上传与拖入
- 多任务并行生成、独立进度条、历史记录、原图保存和原尺寸复制
- 图片双击预览、提示词展开、浅色与深色模式，模型／画幅／分辨率平滑下拉选择
- 生成内容的本机临时文件两小时后自动清理
- GitHub Releases 可选更新，弹窗显示更新内容
- Cloudflare Workers + D1 申请审批；一个手机号和一台机器只允许一个有效绑定
- 管理端审批、驳回、设置期限、解绑、换绑和删除记录
- 内置动态工作台背景，每位用户可调节并保存壁纸不透明度
- 管理端远程切换登录页和工作台主题，支持 GIF、动态 WebP、静态图片、视频和 Wallpaper Engine 场景录制

## 授权流程

客户端填写姓名和手机号提交申请。管理员在管理端设置期限并批准后，客户端会自动进入。设备身份保存在 Windows 用户的 AppData 中，升级安装包不会清除。旧版卡密界面已移除；旧版已激活用户可继续使用到原有效期。本机旧管理库也继续保留，只在管理端“旧版记录”展示。

新版申请数据以 Cloudflare D1 为唯一在线来源。用户端每 30 秒复核一次；在线服务持续不可用超过五分钟时暂停访问，恢复后自动复核。机器码由 Windows MachineGuid 派生。客户端授权不能抵御对本地程序本身的篡改。

## 开发与打包

```powershell
npm ci
npm test
npm run dist:win
npm run dist:admin
```

用户安装包输出到 `release/`，管理端安装包输出到 `release-admin/`。管理端必须留在管理机。首次用管理员密码进入新版管理端时，Cloudflare 管理令牌会迁入本机密码加密管理库，随后删除临时明文文件；令牌不进入仓库或安装包。`approval-service/` 包含 Worker 和 D1 schema；部署需登录有权限的 Cloudflare 账号。

详细操作见 [使用说明.txt](使用说明.txt)。
