# 雄霸AI

由画境工作台升级的 Windows 多模态创作应用。支持文本对话、图像和视频生成；可连接 Geeknow、Grsai 及可识别的 OpenAI 兼容接口。各接口地址分别加密保存 API Key。接口协议无法识别时会提示需要适配。

## 功能

- 文本、绘图和视频模式切换，按已确认能力筛选模型与参考文件
- 画幅、分辨率及视频时长选择；输入 @ 引用文件并调整参考权重
- 文本流式回答、可折叠的思考过程、会话历史与多任务并行生成
- 独立进度条、生成历史、媒体保存、图片原尺寸复制和双击预览
- 固定侧栏与输入框；左侧历史、对话和生成历史分别独立滚动
- 生成内容的本机临时文件两小时后自动清理
- GitHub Releases 可选更新，弹窗显示更新内容
- Cloudflare Workers + D1 申请审批；一个用户名和一台机器只允许一个有效绑定
- 管理端审批、驳回、设置期限、解绑、换绑和删除记录
- 内置动态背景，每位用户可调节并保存壁纸不透明度
- 管理端远程切换登录页和工作台主题，支持 GIF、动态 WebP、静态图片、视频和 Wallpaper Engine 场景录制

## 授权流程

客户端填写用户名和密码提交申请。管理员在管理端设置期限并批准后，客户端会自动进入。设备身份保存在 Windows 用户的 AppData 中，升级安装包不会清除。已批准的设备沿用原身份，无需重新申请。管理端沿用原管理员密码库；服务端仅保存加密后的申请密码。旧卡密在线绑定已撤销。

新版申请数据以 Cloudflare D1 为唯一在线来源。用户端每 30 秒复核一次；在线服务持续不可用超过五分钟时暂停访问，恢复后自动复核。机器码由 Windows MachineGuid 与 BIOS UUID 派生；硬件 UUID 不可用时使用有效的 BIOS 或磁盘序列号。更新后，同一设备凭原有加密设备身份自动迁移旧机器码及绑定期限。客户端授权不能抵御对本地程序本身的篡改。

## 开发与打包

```powershell
npm ci
npm test
npm run dist:win
npm run dist:admin
```

用户安装包输出到 `release/`，管理端安装包输出到 `release-admin/`。管理端必须留在管理机。首次用管理员密码进入新版管理端时，Cloudflare 管理令牌会迁入本机密码加密管理库，随后删除临时明文文件；令牌不进入仓库或安装包。`approval-service/` 包含 Worker 和 D1 schema；部署需登录有权限的 Cloudflare 账号。

## 版本保留规则

保留画境工作台最后一版 `v0.1.17`，以及当前最新雄霸AI版本；壁纸素材库单独保留。新雄霸安装包构建成功后，`postdist:win` 会清理本机 `release/` 中的旧版本；运行 `npm run sync:desktop` 会同步当前安装包并清理桌面交付目录中的旧雄霸版本，不触碰“旧版备份”。发布到 GitHub 时，先确认新版安装包、`latest.yml`、源码包和管理端安装包完整可下载，再删除先前的雄霸 Release 与标签。不要在新版发布前删除旧版更新源。

详细操作见 [使用说明.txt](使用说明.txt)。
