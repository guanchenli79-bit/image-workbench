01 / REQUESTS

待审批申请

用户提交用户名和密码后会出现在这里。批准时设置有效期；申请机器会自动进入工作台。

02 / BINDINGS

设备绑定管理

在线数据库完整保存审批记录。解绑、到期和驳回记录仍会保留；仅手动删除才会移除。换绑需要新机器用同一用户名和密码先提交申请。

ARCHIVE

旧版卡密记录

升级前保存在本机的卡密历史只读保留。旧版卡密在线绑定已撤销；新版申请和绑定以在线数据库为准。

03 / THEMES

用户端页面主题

上传 GIF／动态 WebP、静态 JPG／PNG／WebP 或 MP4／WebM，点击“设为当前”后，用户端登录页和工作台背景会自动同步；每位用户仍可单独调节壁纸不透明度。也可导入 Wallpaper Engine 项目；场景项目可录制 8 秒视频并预览后上传。

WALLPAPER ENGINE

录制动态场景

请先在 Wallpaper Engine 中把场景设为当前桌面壁纸。录制会捕获主显示器 8 秒；请预览后再决定是否上传。
